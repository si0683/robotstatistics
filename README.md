# RobotStatistics

Статистика робота [OsEngine](https://github.com/AlexWan/OsEngine) на вашем сайте: сделки, прибыль, просадка, график доходности. Обновляется раз в минуту.

```
OsEngine (ваш ПК или VPS) → Агент → robot-stats.json на хостинге → виджет на сайте
```

- Работает с любым сайтом: Tilda, WordPress, свой сайт.
- Порты на компьютере открывать не нужно.
- Агент только читает статистику, открывать или закрывать сделки он не умеет.
- Цифры совпадают с журналом OsEngine, потому что их считает сам OsEngine.

> **Статус:** проект на этапе ТЗ. Агент и виджет в разработке.
