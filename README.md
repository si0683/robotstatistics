# RobotStatistics

Статистика робота [OsEngine](https://github.com/AlexWan/OsEngine) на вашем сайте: сделки, прибыль, просадка, график доходности.

OsEngine сам публикует статистику выбранных роботов по ссылкам: **JSON** для сайта, **CSV** для Google Таблиц и Excel, **RSS** для читалок и Telegram. Сайт забирает ссылку и показывает её готовым виджетом.

```
OsEngine «Публичная статистика» → https://stats.ваш-домен.ru/public/<робот>/stats.json → виджет на сайте
```

- Работает с любым сайтом: Tilda, WordPress, свой.
- Лента только читает журналы, управлять роботами через неё нельзя.
- Цифры совпадают с журналом OsEngine.
- OsEngine на VPS — данные круглосуточно; на домашнем ПК — через запись файлов и загрузку на хостинг.

> **Статус:** проект на этапе ТЗ. Модуль для OsEngine и виджет в разработке.

## Структура (план)

```
osengine-module/  — модуль «Публичная статистика» (OsEngine/PublicFeed/) для переноса в OsEngine
widget/           — robot-stats-widget.js
uploader/         — загрузчик файлов на хостинг для домашнего ПК (.NET 10)
examples/         — забор данных сервером сайта (Node, PHP)
TechnicalSpecification/ — ТЗ и инструкция (Obsidian)
```
