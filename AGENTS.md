# Правила работы с репозиторием

## Не публиковать ТЗ на GitHub

Папка `TechnicalSpecification/` содержит технические задания и внутреннюю
документацию. Она **не должна попадать на GitHub**.

- Папка исключена через `.gitignore`, поэтому не добавлять её обратно в индекс
  (`git add -f`, `git add TechnicalSpecification`).
- Не публиковать ТЗ и другим способом: ни в других папках, ни в коммитах,
  ни в описаниях/issue/release, ни в виде отдельных файлов.
- Если ТЗ нужно передать — передавать файлом напрямую, не через git.
- Изменения в `TechnicalSpecification/` фиксировать только локально.
